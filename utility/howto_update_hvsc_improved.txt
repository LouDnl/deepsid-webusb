Note that LOCALHOST means the 'http://chordian/deepsid/' URL. In my setup it was handled
by WampServer, but it doesn't really matter what you're using for LOCALHOST.


LOCALHOST: Backup 
¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯
  1. Open phpMyAdmin for LOCALHOST.
  2. Delete any leftover backup tables.
  3. Truncate the 'files_import' and 'folders_import' tables.
  4. Backup the entire DeepSID database to an SQL file.
  5. Duplicate to 'files_backup' and 'folders_backup' tables.


BOTH: Download
¯¯¯¯¯¯¯¯¯¯¯¯¯¯
 LOCALHOST: 

  1. Download the full HVSC update.
  2. Rename the old HVSC folder to '*_OLD' instead.
  3. Extract and move in the new folder.
  4. Compress the new folder to a 'C64Music.zip' archive.

  5. Copy the 'GROUPS' sub folder from '*_OLD' to the new folder. (Don't include this in the
     compressed archive in step 4 as it's not adapted for One.com's folder system.)
  6. Delete the '*_OLD' folder.

 ONLINE right now:

  1. Run the FTP client.
  2. Delete any previous '*_OLD' folders if you forgot to delete them last time.

  3. Upload 'C64Music.zip' archive to the 'php/_update/' folder.
  4. File Explorer: Delete the local 'C64Music.zip' file.

  5. ADMIN PHP: Run 'Unzip HVSC update' script. THIS TAKES A FEW MINUTES.


LOCALHOST: Prepare
¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯
  1. Update HVSC_VERSION in the 'setup.php' script.
  2. Update HVSC_VERSION in the 'browser.js' script.

  3. Update the version number in the 'About' tab ('index.php').
  4. Update the 'notable' (yellow line) link in the profile page for HVSC (composer table).
  5. Update the top corner link in the profile page to point at the latest CSDb page (same table).


LOCALHOST: Update database
¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯
 Run update script:

  1. Edit 'php/utility/update_hvsc_db_improved.php' in LOCALHOST.
  2. Set the 'TEST_MODE' constant to false.
  3. Make sure 'DB_TABLE_FILES' and 'DB_TABLE_FOLDERS' are set to 'files' and 'folders'.
  4. Save and exit.

  5. ADMIN PHP: Run 'Update database (improved)' script.

  6. Look through the output for any errors.

 Fixing update discrepancies:

  @todo I HOPE BELOW IS NO LONGER AN ISSUE WITH THE NEW IMPROVED SCRIPT ABOVE!

  A problem that can occur is when the HVSC editors haven't been careful enough when adding
  comments in the 'Update##.hvc' file. This can lead to orphan rows in the database with all
  empty or zero values.

  1. To see if you have any of these, go to the SQL box for the 'files' table and execute:

       SELECT * FROM files WHERE collection_path LIKE "%high voltage%" AND data_size = 0

     This will list the problem rows.

  2. Find the problem area in the 'Update##.hvs' file and determine how to rename the collection
     path field to match the SID file correctly. (Is there e.g. a '_' character missing?)
  3. Populate the fields of the SID row by finding the SID file in the various CSV files that
     you have set aside so far. @todo BELOW SCRIPTS SHOULD FILL THE REMAINING FIELDS.
  4. Repeat step 2 to 3 for the other problem rows.

  5. Export the rows to a '01_Patch.sql' file.
  6. Edit the SQL file; remove the ID column and THE DROP LINE!


LOCALHOST: Simple players
¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯¯
  1. Go to this folder: 'utility/hvsc_update/02_players_simple'
  2. Double-click the '_simple.bat' file. (Assuming no errors after this step.)

  3. Export 'files_import' to '02_Players_Simple.sql' file in phpMyAdmin.

  4. Enter the 'files' table and click 'SQL' (empty the box).
  5. Run the following:

       UPDATE files
       INNER JOIN files_import on files_import.collection_path = files.collection_path
       SET files.player = files_import.player

  6. Enter the 'files_import' table and click 'Operations'.
  7. Truncate the table.

LOCALHOST: SID info
-------------------
  1. Edit 'php/utility/update_sidinfo.php' in LOCALHOST.
  2. Make sure the 'TEST_LIMIT' constant is set to 0.
  4. Save and exit.

  5. ADMIN PHP: Run 'Update with SIDInfo' script. THIS TAKES A FEW MINUTES.

  6. Export 'files_import' to '05_SIDInfo.sql' file.

  7. Enter the 'files' table and click 'SQL' (empty the box).
  8. Run the following:

       UPDATE files
       INNER JOIN files_import on files_import.collection_path = files.collection_path
       SET files.type = files_import.type,
           files.version = files_import.version,
           files.player_type = files_import.player_type,
           files.player_compat = files_import.player_compat,
           files.clock_speed = files_import.clock_speed,
           files.sid_model = files_import.sid_model,
           files.data_offset = files_import.data_offset,
           files.data_size = files_import.data_size,
           files.load_addr = files_import.load_addr,
           files.init_addr = files_import.init_addr,
           files.play_addr = files_import.play_addr,
           files.subtunes = files_import.subtunes,
           files.start_subtune = files_import.start_subtune,
           files.name = files_import.name,
           files.author = files_import.author,
           files.released = files_import.released,
           files.hash = files_import.hash

  9. Enter the 'files_import' table and click 'Operations'.
 10. Truncate the table.
